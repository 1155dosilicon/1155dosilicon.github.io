# projeto principal

Um agente de IA que programa com você.

App de desktop para Windows e Linux que lê o repositório, edita arquivos, roda comandos e delega tarefas a subagentes, com cada ação visível na tela.

siliconflower v0.14.0 · licença MIT

IA agêntica,
no seu computador.

interface
app de desktop (uma janela por projeto) ou no navegador com siliconflower gui
ferramentas
30 nativas: arquivos, busca, comandos, web, memória e worktrees
agentes
subagentes e tarefas em background, com diagnóstico embutido (🩺)
modelos
qualquer API compatível com a da OpenAI (SiliconFlow, OpenRouter, OpenAI, Xiaomi MiMo)
extensões
servidores MCP (stdio ou HTTP), hooks e skills em Markdown
plataforma
Windows 10/11 e Linux x86_64 (.exe, .deb e AppImage)
