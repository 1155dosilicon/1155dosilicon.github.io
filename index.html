01 / Projeto principal

Um agente de engenharia no terminal.

CLI/TUI que lê o repositório, edita arquivos, roda comandos e delega tarefas a subagentes, com cada ação visível na tela.

SILICONFLOWER · v0.2.9 · MIT

IA agêntica,
direto no terminal.

  • ferramentas34 nativas: arquivos, busca, comandos, web, memória e worktrees
  • agentessubagentes e tarefas em background
  • modelosqualquer API compatível com OpenAI (SiliconFlow, OpenRouter, OpenAI, Xiaomi MiMo)
  • extensõesservidores MCP, hooks e skills em Markdown
  • plataformaWindows · port para Linux/macOS em siliconflower-nix

PowerShell
# clone e instale
git clone https://github.com/1155dosilicon/siliconflower.git
cd siliconflower
bun install

# wizard de configuração na 1ª execução
bun run start

# ativa a memória de projeto na pasta atual
siliconflower init
