# projeto principal

Um agente de engenharia no terminal.

CLI/TUI que lê o repositório, edita arquivos, roda comandos e delega tarefas a subagentes, com cada ação visível na tela.

siliconflower v0.2.9 · licença MIT

direto no terminal.

34 nativas: arquivos, busca, comandos, web, memória e worktrees
agentes

modelos
qualquer API compatível com OpenAI (SiliconFlow, OpenRouter, OpenAI, Xiaomi MiMo)
extensões
servidores MCP, hooks e skills em Markdown

Windows · port para Linux/macOS em siliconflower-nix
